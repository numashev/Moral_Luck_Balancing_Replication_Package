# Moral_Luck_Balancing_Replication_Package
Replication package for moral and luck balancing

## Replication

The data collected as part of the study can be found in the Data folder. The code used to reproduce the tables, figures, and statistics quoted in the study can also be found as a .qmd file within this folder.

The .qmd file requires a root directory to be set in order for the code to function. Within this root directory, the folders 'Data' (containing the data used) and 'Writing' (where the tables/figures are exported to) are also required. The current root directory listed in the file is the one used by the author. Both the 'Data' and 'Writing' folders have been created in this repository for convenience.

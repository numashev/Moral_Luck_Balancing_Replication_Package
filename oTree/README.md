# Moral-Balancing-Experiment

oTree implementation of the Moral and Luck Balancing experiment.

## Running locally

1. Install oTree in a Python environment.
2. Set an oTree secret key:

   ```sh
   export OTREE_SECRET_KEY="your-local-secret"
   ```

3. Optionally set an admin password:

   ```sh
   export OTREE_ADMIN_PASSWORD="your-admin-password"
   ```

4. From this folder, start the development server:

   ```sh
   otree devserver
   ```
